# 临时工作区（Temporary workspaces）

在侧栏“新建会话”按钮旁加一个“新建临时会话”按钮：每次点击在 `~/.dsh/temp-workspace` 下创建 `tmp-01`、`tmp-02`… 独立目录，并在其中新建一个不依赖项目目录的会话。

## 使用

- **入口**：展开侧栏时，New Session 行右侧的文件夹＋按钮；窄侧栏（rail）时它堆叠在 New Session 图标下方。
- **点击后**：先确保 `~/.dsh/temp-workspace` 存在，再顺延创建 `tmp-NN`，把该目录注册为同名工作区（`tmp-NN`）并创建会话；会话自动打开，可直接输入。
- **再次点击**：总是创建**新的** `tmp-NN` 目录和会话，不复用上一个临时目录。
- **普通 New Session**：临时会话打开后，普通 New Session 按钮会继续在当前 `tmp-NN` 工作区里新建；要新的临时目录请再点临时按钮。
- **失败提示**：目录、工作区或会话创建失败时，底部出现可手动关闭的错误提示；创建期间按钮显示加载标记，重复点击会被忽略。

## 目录与命名

```
~/.dsh/temp-workspace/          # 临时根目录，首次点击时创建
├── tmp-01/                     # 每个临时会话一个目录，也是它的工作区
├── tmp-02/
└── ...
```

- 有应用内目录选择器时，编号顺延并靠“创建目录失败即已存在”重试来避免重名。
- 目录选择器是原生系统选择器时（无法由插件列目录/建目录），改用带时间戳的 `tmp-<base36>-<随机>` 名；会话创建时由 Host 递归创建目录，Host 半再补挂工作区。
- 所有临时会话的工作区标题就是目录名（`tmp-NN`），所以在侧栏按工作区分组时每个临时会话各占一个小分组；侧栏切到扁平列表时只显示会话标题。
- 插件不自动清理：目录、工作区注册、会话日志都保留。

## 为什么要“一个临时会话一个工作区”

DSH 的新会话页只有在空白会话**归属某个已经登记的工作区**时才启用输入框；仅带 `cwd`、不属任何工作区的空白会话会被当作“工作区已删除”，输入框保持禁用。而 `session.create` 不能同时接收 `workspaceId` 和 `cwd`，工作区挂载又要求工作区路径与会话记录 cwd 完全一致。因此实现上只能：

1. 先建 `tmp-NN` 目录，再把它注册为工作区，最后以 `workspaceId` 创建会话（正常路径，Host 端原子挂载）；或
2. 仅以 `cwd` 创建会话，由 Host 半在 `agent/created` 后把该目录补登记为工作区并挂载（原生选择器回退路径）。

这也意味着“临时工作区”在 UI 上表现为多个 `tmp-NN` 小组，而不是一个统一分组。若更在意分组整洁，可改为“一个临时工作区 + working-directory 切换每个会话的工作目录”，代价是 `tmp-NN` 不在侧栏分组中可见。

## 清理

1. 在侧栏删除 `tmp-NN` 工作区注册（只删注册，不删目录和会话日志）。
2. 再按需删除 `~/.dsh/temp-workspace/tmp-NN` 目录。
3. 不要在会话还是空白时删除工作区注册：空白会话会失去归属，输入框会再次被禁用。先发一条消息，或归档/放弃该会话。

插件不会自动删除任何临时目录或工作区注册。

## 已知限制

- 点击会立即创建新会话；当前空白会话里未发送的草稿仍留在原会话，不会迁移。
- 原生目录选择器下命名退化为时间戳，且 Host 端补挂是尽力而为；失败时只记录 Host 日志并提示刷新。
- 临时根目录位于 `~/.dsh` 内，与凭据、会话数据同目录。临时会话的文件策略仍以自己的 `tmp-NN` 工作区为根；如果使用 danger-full-access，它也能读到 `~/.dsh` 下的敏感文件，建议临时会话使用 workspace-write。
- 按钮使用原生 `title` 作为悬停提示，而不是带主题样式的 Tooltip；键盘焦点有 `aria-label`，但不会弹出视觉提示。
- 插件只覆盖 Web 客户端；没有为 Agent 提供创建临时目录的工具。

## 安装

运行时副本放在 `~/.local/share/dsh-plugins/dsh-temp-workspace/`，DSH 通过链接加载：

```sh
dsh plugin --profile web add ~/.local/share/dsh-plugins/dsh-temp-workspace
```

或使用图形界面 **设置 → 插件 → 添加插件**，选择该目录。安装后刷新页面。

## 打包分发

```sh
cd dsh-temp-workspace
npm pack
# local-dsh-temp-workspace-1.0.0.tgz
```

`npm pack` 会自动包含 README、`docs/` 预览图、双语文案和图标。

## 停用

设置 → 插件里关闭 `@local/dsh-temp-workspace`（或整包禁用）即可移除侧栏按钮；已创建的 `tmp-NN` 目录、工作区注册和会话都保留。
