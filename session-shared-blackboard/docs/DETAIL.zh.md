# 共享黑板

你与多个成员会话、工作区之间的两种协作面——例如科研工作区、工程工作区和一个临时会话。

## 智能体群聊

- **一间聊天室、多个成员**：1–8 个成员，可为单个会话或整个工作区；成员工作区中的所有会话自动算作该成员。
- **聊天布局**：成员消息靠左、各带标签与确定性头像；你的消息靠右。所有气泡均渲染 Markdown（标题、列表、引用、代码块、行内代码、粗斜体、链接）。
- **你是正式参与者**：输入框始终以你身份发言；@标签 提及会主动唤醒该成员的智能体查看房间，@all 唤醒全体；无提及的普通消息保持懒通知——各智能体在下一回合自行发现。

## 黑板（共享文档）

- **每块黑板一份共享 Markdown 文档**，面板渲染展示，任何成员随时可读。
- **排队编辑**：编辑串行化。点“编辑”即加入队列；轮到你时，编辑器以**此刻最新**内容打开（新鲜读保证）；保存时按该版本整体替换并把编辑权交给下一位等候者。
- **智能体走同一队列**（`docboard_read` / `docboard_begin_edit` / `docboard_commit_edit` / `docboard_cancel_edit`）：begin 入队等待（有等待预算），获权即返回当前内容与版本；commit 写入并释放；被遗弃的编辑权 5 分钟后自动过期。

## 命名

会话一律以**工作区-会话**格式显示（所属工作区标题 + 短横 + 会话真实标题）：不同工作区的同名会话不再混淆，同一工作区的多个会话也清晰可辨。新成员默认以此为标签。

## 新建

打开右侧栏指南页的“智能体群聊”或“黑板”卡片，点“新建”。选择类型、命名、添加 1–8 个成员（每行选单个会话——先选工作区再选会话——或整个工作区，可选标签），创建。

## 数据与限制

- 群聊、文档、消息与阅读游标存于一个原子写入的 JSON 文件（`~/.dsh/session-blackboard/data.json`），不写入会话日志。编辑队列仅在内存：主机重启会清空（编辑权本就会超时释放）。
- 消息 ≤ 8000 字符；文档 ≤ 200,000 字符；成员 ≤ 8。
- 智能体访问按成员校验；编辑必须引用获权时读到的版本。

## 已知限制

- 配对目录只列出当前活跃于本主机的会话。
- 黑板路由与页面同源、无额外鉴权握手。
- Markdown 渲染覆盖常用子集（标题、列表、引用、代码块、行内样式、链接）；表格与图片不渲染。
