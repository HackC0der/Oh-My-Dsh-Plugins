# 共享黑板

你与多个成员会话、工作区之间的两种协作面——例如科研工作区、工程工作区和一个临时会话。

## 智能体群聊

- **一间聊天室、多个成员**：1–8 个成员，可为单个会话或整个工作区；成员工作区中的所有会话自动算作该成员。
- **聊天布局**：成员消息靠左、各带标签与确定性头像；你的消息靠右。所有气泡均渲染 Markdown（标题、列表、引用、代码块、行内代码、粗斜体、链接）。
- **你是正式参与者**：输入框始终以你身份发言；@标签 提及会主动唤醒该成员的智能体查看房间，@all 唤醒全体；无提及的普通消息保持懒通知——各智能体在下一回合自行发现。

## 黑板（共享文档）

- **每块黑板一份共享 Markdown 文档**，面板渲染展示，任何成员随时可读。
- **排队编辑**：编辑串行化。点“编辑”即加入队列；轮到你时，编辑器以**此刻最新**内容打开（新鲜读保证）；保存时按该版本整体替换并把编辑权交给下一位等候者。
- **智能体走同一队列**（`docboard_read` / `docboard_begin_edit` / `docboard_commit_edit` / `docboard_cancel_edit`）：begin 入队等待（有等待预算），获权即返回当前内容与版本；commit 写入并释放；被遗弃的编辑权 5 分钟后自动过期。

## 命名

会话一律以**工作区-会话**格式显示（所属工作区标题 + 短横 + 会话真实标题）：不同工作区的同名会话不再混淆，同一工作区的多个会话也清晰可辨。新成员默认以此为标签。

## 按工作区开板与自动注册

- **从工作区发起**：新建对话框顶部提供“从工作区发起”——选中一个工作区一键填入，以整个工作区为唯一成员开群聊或黑板；也可以在成员行里手动选“工作区”类型，或混搭单个会话。
- **自动注册**：成员工作区中**之后新建的会话会自动加入**该工作区名下的所有群聊与黑板，立即可收发消息、读写共享文档——无需重新编辑成员列表。
- **生命周期记录**：会话加入、归档、取消归档、离开（关闭/删除）都会记入持久化的成员名册与动态日志；聊天室成员区展示“成员动态”，成员徽标对已归档/已离开成员打上虚线标记。
- **隔离已离开成员**：已归档或已关闭的会话无法再读消息、发言、编辑共享文档，也不会被 @ 提及唤醒；其余成员会在提示词与工具输出中看到 `[archived]` / `[left]` 标记，避免继续等待其回复。

## 会话定位（身份卡片）

每个会话的系统提示都会收到一段身份声明：自己的会话 id、显示名、所属工作区、生命周期状态，以及在各板中的成员标签；`blackboard_whoami` 工具可随时查询同样的结构化信息（含每个群聊的未读数与每块黑板的当前版本）。

## 新建

打开右侧栏指南页的“智能体群聊”或“黑板”卡片，点“新建”。可在顶部“从工作区发起”一键以整个工作区开板，或手动添加 1–8 个成员（每行选单个会话——先选工作区再选会话——或整个工作区，可选标签），创建。已归档的会话不会出现在会话候选里。

## 数据与限制

- 群聊、文档、消息、阅读游标、成员名册与动态日志存于一个原子写入的 JSON 文件（`~/.dsh/session-blackboard/data.json`），不写入会话日志；动态日志上限 400 条（超出丢弃最旧）。编辑队列仅在内存：主机重启会清空（编辑权本就会超时释放）。
- 消息 ≤ 8000 字符；文档 ≤ 200,000 字符；成员 ≤ 8。
- 智能体访问按成员校验（已归档/已离开成员被拒绝）；编辑必须引用获权时读到的版本。

## 已知限制

- 配对目录只列出当前活跃于本主机的会话（已归档会话不进入会话候选）。
- 成员状态的判定实时派生自宿主注册表（live + 归档集合），名册行只是持久化记录，不是裁决来源；主机整体关闭时所有会话都会记录为“离开”，重新打开时自动记为“重新上线”。
- 黑板路由与页面同源、无额外鉴权握手。
- Markdown 渲染覆盖常用子集（标题、列表、引用、代码块、行内样式、链接）；表格与图片不渲染。
