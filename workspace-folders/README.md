# 工作区文件夹（Workspace folders）

在左侧边栏把已有工作区收进**虚拟文件夹**：文件夹只是视图分类，不会在磁盘上创建、移动或重命名任何目录。适合把“开发”“论文”“测试”等项目分组收容。

## 使用

- **新建文件夹**：左侧“工作区”标题栏的文件夹＋图标，输入名称后回车（Esc 取消）。
- **归类工作区**：把工作区行拖到文件夹行上；拖到列表空白处或右键工作区选“移出文件夹”即可回到根级。也可以右键工作区选“移入文件夹”再选目标文件夹。
- **重命名 / 删除文件夹**：点文件夹右侧的“…”（或右键文件夹）。删除后工作区回到根级，并出现一个可撤销的提示。
- **展开 / 收起**：点文件夹行或工作区行切换；搜索时自动全部展开。
- **会话**：点行打开；“…”菜单里有重命名、置顶、归档、复制会话 ID 等操作（这些来自内置工作区功能）。已归档会话灰显，点击会提示不可打开；可在“…”菜单里恢复。
- **新建会话**：工作区行悬停出现的新会话按钮。
- **添加工作区**：标题栏的添加图标打开插件自带的目录选择对话框（可新建子目录）。

## 数据保存

文件夹归属、文件夹名、展开状态保存在**当前浏览器**的 `localStorage`（键 `dsh.workspace.folders.v1`）：

- 重启 DSH、升级 DSH 版本、插件重新加载都不会丢失。
- 换浏览器、换设备或清除站点数据后不会同步，需要重新分组。
- 工作区在别处被删除时，对应的文件夹成员会被自动清理。

## 与内置浏览器相比的已知取舍

该插件接管了左侧工作区区域（`sidebar.workspaces` 槽位，插件以更低优先级遮蔽内置浏览器；停用插件即恢复原样）。受槽位声明规则限制，接管方不能再次声明内置浏览器的子槽位，因此：

- 置顶/归档的悬停按钮不再显示，但仍在会话“…”菜单中可用；
- 会话行不再显示内置的“前置/后置”装饰（例如日程图标）；
- 搜索是本地的标题/路径过滤，不做内置的会话全文搜索；
- 视图选项（按工作区树分组、手动排序、已归档筛选）不再提供，改为文件夹分组；
- 工作区顺序沿用 DSH 注册顺序，不提供拖拽排序。

## 停用

设置 → 插件里关闭 `@local/workspace-folders`（或整包禁用）即可恢复内置工作区列表；已有的文件夹数据会保留在浏览器里，重新启用后继续使用。
