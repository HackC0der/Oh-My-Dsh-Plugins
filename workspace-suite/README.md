# 工作区套件（Workspace suite）

一个插件同时提供两个侧栏能力：

1. **虚拟分组**：把已有工作区收进可任意嵌套的虚拟分组（分组 → 子分组 → … → 工作区 → 会话）。分组只是视图分类，不会在磁盘上创建、移动或重命名任何目录。
2. **临时会话**：在侧栏“新建会话”按钮旁加一个“新建临时会话”按钮，每次点击在 `~/.dsh/temp-workspace` 总目录下创建 `tmp-01`、`tmp-02`… 独立目录，并在其中新建一个不依赖项目目录的会话。

本插件由 `@local/workspace-folders` 1.2.0 与 `@local/dsh-temp-workspace` 1.1.0 合并而来，两者功能不变、相互配合不再需要安装两个包。

## 使用

### 分组

- **新建分组**：左侧“工作区”标题栏的文件夹＋图标，输入名称后回车（Esc 取消）。
- **嵌套分组**：右键分组选“新建子分组”，在该分组下直接创建；或把一个分组行**拖到另一个分组行上**完成挂靠（拖到列表空白处回到根级）。分组不能拖进自己或自己的子孙分组。
- **归类工作区**：把工作区行拖到任意层级的分组行上；拖到列表空白处或右键工作区选“移出分组”即可回到根级。也可以右键工作区选“移入分组”，再从带路径的子菜单里选目标（如“开发 / 前端”）。
- **移动分组**：右键分组选“移动分组到…”，子菜单里同样显示“父 / 子”路径。
- **重命名 / 删除分组**：点分组右侧的“…”（或右键分组）。删除后其子分组和成员工作区都并回上一级，并出现一个可撤销的提示（撤销会原样恢复整棵子树）。
- **展开 / 收起**：点分组行或工作区行切换；搜索时自动全部展开。分组行右侧的数字是**整棵子树**的工作区总数。
- **已归档会话默认隐藏**：标题栏的眼睛按钮可切换显示/隐藏已归档会话；显示时已归档会话灰显，点击会提示不可打开，可在“…”菜单里恢复。
- **会话**：点行打开；“…”菜单里有重命名、置顶、归档、复制会话 ID 等操作（这些来自内置工作区功能）。
- **新建会话**：工作区行悬停出现的新会话按钮。
- **添加工作区**：标题栏的添加图标（圆柱＋号，与分组按钮外观不同）打开插件自带的目录选择对话框（可新建子目录）。

### 临时会话

- **入口**：展开侧栏时，New Session 行右侧的文件夹＋按钮；窄侧栏（rail）时它堆叠在 New Session 图标下方。
- **点击后**：先确保 `~/.dsh/temp-workspace` 存在，再顺延创建 `tmp-NN`，把该目录注册为同名工作区（`tmp-NN`）并创建会话；会话自动打开，可直接输入。
- **再次点击**：总是创建**新的** `tmp-NN` 目录和会话，不复用上一个临时目录。
- **普通 New Session**：临时会话打开后，普通 New Session 按钮会继续在当前 `tmp-NN` 工作区里新建；要新的临时目录请再点临时按钮。
- **失败提示**：目录、工作区或会话创建失败时，底部出现可手动关闭的错误提示；创建期间按钮显示加载标记，重复点击会被忽略。
- 有应用内目录选择器时，编号顺延并靠“创建目录失败即已存在”重试来避免重名；原生系统选择器下改用带时间戳的 `tmp-<base36>-<随机>` 名，由 Host 半在 `agent/created` 后补登记工作区并挂载。

## 临时工作区文件夹

`~/.dsh/temp-workspace` 下的 `tmp-*` 临时工作区不散落各处，固定收入侧栏**置顶的“临时工作区”分组**，不占用、也不可拖入用户分组：

- **隐藏即“删除”**：临时工作区行悬停的眼睛斜杠按钮（或右键菜单“隐藏临时工作区”）只把它从列表移除——工作区注册、磁盘目录、会话与日志全部保留；隐藏后底部会出现带“恢复显示”按钮的提示，一键找回。
- **恢复**：分组内底部有“已隐藏（n）”分区（点它或分组行的眼睛按钮展开），里面灰显、缩进列出被隐藏的临时工作区，行上的眼睛按钮或右键“恢复显示”把它放回主列表。
- **只影响本列表**：隐藏只过滤侧栏显示；被隐藏的工作区在其他列出工作区的界面（如新会话的工作区选择器）中仍会出现。
- 未连接 Host（拿不到主目录）时临时分组暂不显示，连接后自动出现。

## 图标区分

- **分组**：实心文件夹轮廓（闭合 / 打开两种状态）。
- **工作区**：描边的圆柱堆叠图标，与分组在形状和粗细上都不同；当前会话所在的工作区图标会高亮为主题色。
- **未分组**：收件箱托盘图标，表示“不在任何工作区里的会话”。

## 数据保存

分组树（分组名、父子关系、成员归属）、展开状态、归档显示开关，以及临时分组的展开/隐藏状态（含被隐藏的 `tmp-*` 路径清单）都保存在**当前浏览器**的 `localStorage`（键 `dsh.workspace.folders.v2`，与 workspace-folders 1.x 相同，升级后原有分组直接沿用；旧版 `v1` 数据首次加载时自动迁移）：

- 重启 DSH、升级 DSH 版本、插件重新加载都不会丢失。
- 换浏览器、换设备或清除站点数据后不会同步，需要重新分组。
- 工作区在别处被删除时，对应的分组成员会被自动清理；空分组保留。
- 数据损坏时安全回退为空状态，不会影响工作区本身。

## 为什么要“一个临时会话一个工作区”

DSH 的新会话页只有在空白会话**归属某个已经登记的工作区**时才启用输入框；仅带 `cwd`、不属任何工作区的空白会话会被当作“工作区已删除”，输入框保持禁用。而 `session.create` 不能同时接收 `workspaceId` 和 `cwd`，工作区挂载又要求工作区路径与会话记录 cwd 完全一致。因此实现上只能：

1. 先建 `tmp-NN` 目录，再把它注册为工作区，最后以 `workspaceId` 创建会话（正常路径，Host 端原子挂载）；或
2. 仅以 `cwd` 创建会话，由 Host 半在 `agent/created` 后把该目录补登记为工作区并挂载（原生选择器回退路径）。

在侧栏里这些 `tmp-NN` 小组统一收进置顶的“临时工作区”分组呈现。

## 清理

1. 日常“删掉”一个临时工作区：直接**隐藏**（见上节），内容和会话都保留、可随时恢复。
2. 真正清理时：先用内置“删除工作区”删掉 `tmp-NN` 的注册（只删注册，不删目录和会话日志），再按需删除 `~/.dsh/temp-workspace/tmp-NN` 目录。
3. 不要在会话还是空白时删除工作区注册：空白会话会失去归属，输入框会再次被禁用。先发一条消息，或归档/放弃该会话。（隐藏不受此限制：注册仍在，会话照常可用。）

插件不会自动删除任何临时目录或工作区注册；隐藏也不会删除任何内容。

## 与内置浏览器相比的已知取舍

该插件接管了左侧工作区区域（`sidebar.workspaces` 槽位，插件以更低优先级遮蔽内置浏览器；停用插件即恢复原样）。受槽位声明规则限制，接管方不能再次声明内置浏览器的子槽位，因此：

- 置顶/归档的悬停按钮不再显示，但仍在会话“…”菜单中可用；
- 会话行不再显示内置的“前置/后置”装饰（例如日程图标）；
- 搜索是本地的标题/路径过滤，不做内置的会话全文搜索；
- 视图选项（按工作区树分组、手动排序、已归档筛选）不再提供，改为分组树＋标题栏归档开关；
- 工作区顺序沿用 DSH 注册顺序，不提供拖拽排序。

## 其他已知限制

- 点击临时按钮会立即创建新会话；当前空白会话里未发送的草稿仍留在原会话，不会迁移。
- 原生目录选择器下临时目录命名退化为时间戳，且 Host 端补挂是尽力而为；失败时只记录 Host 日志并提示刷新。
- 临时根目录位于 `~/.dsh` 内，与凭据、会话数据同目录。临时会话的文件策略仍以自己的 `tmp-NN` 工作区为根；如果使用 danger-full-access，它也能读到 `~/.dsh` 下的敏感文件，建议临时会话使用 workspace-write。
- 临时按钮使用原生 `title` 作为悬停提示，而不是带主题样式的 Tooltip；键盘焦点有 `aria-label`，但不会弹出视觉提示。
- 插件只覆盖 Web 客户端；没有为 Agent 提供创建临时目录的工具。

## 安装

运行时副本放在 `~/.local/share/dsh-plugins/workspace-suite/`，DSH 通过链接加载：

```sh
dsh plugin --profile web add ~/.local/share/dsh-plugins/workspace-suite
```

或使用图形界面 **设置 → 插件 → 添加插件**，选择该目录。安装后刷新页面。

从旧版升级（已安装 `@local/workspace-folders` 和/或 `@local/dsh-temp-workspace`）：先移除旧插件再安装本插件（或反过来，两者不要同时启用——同时启用时分组浏览器只有一份，但临时按钮会出现两份）。浏览器里的分组数据保存在 `localStorage`，升级后直接沿用。

## 打包分发

```sh
cd workspace-suite
npm pack
# local-workspace-suite-1.0.0.tgz
```

`npm pack` 会自动包含 README、`docs/` 预览图、双语文案和图标。

## 停用

设置 → 插件里关闭 `@local/workspace-suite`（或整包禁用）即可恢复内置工作区列表并移除临时会话按钮；已有的分组数据会保留在浏览器里，已创建的 `tmp-NN` 目录、工作区注册和会话也都保留。

- 两份原插件的假服务覆盖（正常原子路径、原生选择器回退、创建失败清理、共享 busy 防重、错误提示、Host 挂载与 subagent 跳过；temp 路径判定边界、隐藏去重与持久化、恢复、prune 清理、右键菜单 hide↔restore 切换）对合并版同样有效。
